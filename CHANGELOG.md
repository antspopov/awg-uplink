# Changelog

Формат: секция `## X.Y.Z`. При обновлении через панель показываются все секции **между** текущей и новой версией.

- Поле ping и статус туннеля: значения по умолчанию в UI, учёт `.conf` в `/etc/wireguard/`.

## 1.1.6

### Firewall / UFW
- Исправлена ошибка UFW при новой установке: зарезервированные порты (SSH, веб-панель, MTProto и др.) всегда открываются на нужном интерфейсе; без `EGRESS_DEV` правила UFW не применяются преждевременно.

### Резервный туннель (два AWG)
- Второй туннель (`awg-uplink-2`): импорт `.conf`, включение/выключение, удаление конфига, перезапуск.
- Health-check (ping) по каждому включённому туннелю с настраиваемым интервалом.
- Автоматический failover: при потере связи на активном туннеле трафик переключается на второй; при восстановлении — обратно.
- Блокировка отключения/удаления единственного **рабочего** туннеля, если маршрут, georouting или MTProto завязаны на туннель.
- Синхронизация активного интерфейса с georouting (таблица 207, nft, `interfaces.env`).

### Панель и маршрутизация
- Статус маршрутизации при недоступном туннеле; блокировка georouting/MTProto без рабочего туннеля.
- Исправлена смена режима маршрутизации (`interfaces.env` / Path).
- UI: мерцающая кнопка «Импорт», блокировка «Перезапуск» без конфига, очистка черновика после импорта.

### Обновление из панели
- После self-update: применение туннелей, перезапуск ifaces/firewall/geo/DNS-таймеров (не только webui).
- В окне обновления — все секции CHANGELOG между версиями или список коммитов с GitHub.
